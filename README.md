# CalAPA Help

A student-facing guide to CalAPA Version 09: cycle overviews, submission limits,
complete rubrics, original template images, fictional examples, public-data
reading support, adjustable text, and connected navigation.

This is an instructional resource, not an official CTC site, scored exemplar,
or substitute for the current assessment guides, templates, policies, and
preparation-program directions. Candidates collect their own permitted evidence,
make their own decisions, select their own submission evidence, and author their
own responses.

  Historical measure/DASS comparability remains qualified; annual rates are not

  fictional transcript examples. Optional research reading includes the supplied
  one-sample t-test decoder, kept distinct from the public school evidence.
- Four reviewed paragraph revisions are applied by `cycle-connections.js` after
  the baseline curriculum and research integration load. This preserves the source

  script or run an older master builder over the current workbook.

- Light/dark themes follow the initial system preference and remember the user's

  exact sections of the Intro to Research course. The master records these on
  Lecture Weave and Response Weave; the original Course Text baseline is retained.

- Evidence Library includes enlarged charts, PNG/CSV downloads, denominators,
